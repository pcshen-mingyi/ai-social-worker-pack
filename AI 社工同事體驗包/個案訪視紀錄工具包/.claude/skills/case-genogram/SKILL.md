# 個案訪視紀錄——家系圖

從逐字稿/筆記萃取家庭成員與關係，自動畫成家系圖，嵌入訪視紀錄 docx 的
「家系圖」區塊。**不需要跟使用者確認，直接畫圖嵌入。**

**重要**：不管家庭結構多複雜，都要嘗試自動畫圖，不要只停在「列出關係表」就結束。
複雜家庭的自動排版可能不夠精確，這是已知限制——照畫就好，不用因為複雜就放棄，
畫完後誠實提醒使用者「複雜家庭建議人工檢查排版」即可。

**不要讓使用者選世代範圍或成員稱謂規則**——這兩件事都由系統自動判斷，
細節見 `references/notation-legend.md`。

## 使用時機

- `case-visit-record` 步驟 4 完成後，接著執行（不需要使用者另外要求，是固定的下一步）
- 使用者單獨提出「幫我畫家系圖」並提供家庭關係描述

## 流程

> 下面指令裡的 `scripts/`、`references/` 都是相對於**這個 skill 資料夾**（也就是
> 這份 SKILL.md 所在目錄）的路徑，執行時請換成完整路徑。

### 1. 判斷世代範圍（自動，不問使用者）

執行：

```bash
python3 scripts/classify_scope.py --case-id CASE-001 --data {shared/config.json 的 case_data_xlsx}
```

（`--data` 路徑同 `case-visit-record` 步驟 2 用的同一份 xlsx）。回傳的分類只會是
「幼兒青少年案主／中壯年案主／老年案主」＋對應世代範圍，**不會回傳出生年月日**。
查不到時（互動模式、案主不在表裡），改用逐字稿裡的年齡線索自行判斷。
完整規則見 `references/notation-legend.md`「世代範圍」章節。

### 2. 萃取家庭成員與關係

依步驟 1 判斷出的世代範圍，只萃取範圍內的成員，從逐字稿/筆記中辨識：

- 每位成員：**以案主為中心的稱謂**（案主／案父／案母／案妻／案夫／案子／案女／
  案兄／案姊／案弟／案妹……，對照表見 `references/notation-legend.md`「成員稱謂」）、
  性別（由稱謂判斷）、是否已故、是否為索引個案
- 世代：案主為 0，往上代數遞減、往下代數遞增
- 伴侶狀態（互斥，最多擇一）：結婚／同居／分居／離婚
- 情感關係（可與伴侶狀態疊加）：親密／過度親密／疏離／衝突／溝通中斷／
  衝突又親密（逐字稿沒有明確描述就不要加，不要臆測）
- 親子關係：由父/母指向子女
- **身障手冊**：若逐字稿或個案資料提及某成員持有身障手冊，設定 `"disabled": true`，
  畫圖時男性方框右半邊填黑

手足關係不用特別列出——只要幾個子女的 `parent` 都指向同一組父母，畫圖時會自動
排在同一排；長幼順序需要標示時用 `note` 欄位加稱謂（例如「大哥」）。

**`note` 欄位只用於長幼排序稱謂**（如「大哥」「長女」），不要把病名、收入、
職業、居住狀況等生活資訊放進去——這些屬於敘事欄位，不應出現在家系圖符號旁。

### 3. 寫成 JSON 並畫圖

依 `scripts/render_genogram.py` 開頭的 JSON 格式寫入暫存檔，然後執行：

```bash
python3 scripts/render_genogram.py \
  --data /tmp/family.json \
  --png /tmp/family.png \
  --embed-docx {case-visit-record 產出的 docx} \
  --out {同一份 docx}
```

腳本會用固定符號畫圖（見 `references/notation-legend.md`），存成 PNG，
並直接嵌入 docx「家系圖」標題下方（圖例文字那一列，範本圖例已同步更新為
完整版，跟畫出來的圖例一致）。

如果使用者只想要單獨的家系圖圖片、還沒有訪視紀錄 docx，可以省略
`--embed-docx`/`--out`，只產出 PNG 檔給使用者。

### 5. 完成後

告訴使用者輸出位置，並提醒：這是自動排版，成員多、關係複雜時版面可能不夠
美觀，建議人工檢查一次；圖例已跟訪視紀錄範本印刷的完整版圖例對齊。

家系圖嵌入完成後，訪視紀錄 docx 即為最終版本，接著使用 `case-visit-approval` skill
寄給主管確認歸檔。
