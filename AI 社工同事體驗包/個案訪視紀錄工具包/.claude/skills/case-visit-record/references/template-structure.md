# 範本結構參考

`templates/明怡個案紀錄表-demo版.docx` 只有一個表格（`doc.tables[0]`），共 16 列，
用 `python-docx` 開啟後各列（row index）對應如下：

| row | 內容 |
|---|---|
| 0 | 姓名 / 出生年月日 |
| 1 | 身份證字號 / 聯絡電話（家電、手機） |
| 2 | 性別（checkbox）/ 婚姻狀況（checkbox） |
| 3 | 戶籍地址（純文字） |
| 4 | 現住地址（checkbox：同上 / 其他＋地址） |
| 5 | 教育程度（checkbox） |
| 6 | 居住狀況（checkbox，含「與其他人同住：關係」） |
| 7 | 職業（checkbox） |
| 8 | 經濟狀況（checkbox＋金額填空） |
| 9 | 宗教信仰（checkbox） |
| 10 | 「訪視紀錄」標題列 |
| 11 | 訪視紀錄本文（見下方段落順序） |
| 12 | 「處遇計畫建議」標題列 |
| 13 | 處遇計畫建議本文（見下方段落順序） |
| 14 | 「家系圖」標題列 |
| 15 | 家系圖圖例文字（家系圖圖片由 case-genogram skill 插入這一列） |

row 0–9 是「身分欄位」，一律透過 `scripts/fill_identity.py` 寫入，不經過模型。
row 11、13 是「敘事欄位」，透過 `scripts/fill_narrative.py` 寫入，內容由模型依逐字稿草擬。

## row 11（訪視紀錄本文）段落順序

1. `訪視紀錄｜第　　次`
2. `訪視日期：＿＿＿＿＿＿＿＿　　訪視方式：□電話　□視訊　□實地`
3. `訪視地點：＿＿＿＿＿＿＿＿　　訪視人員：＿＿＿＿＿＿＿＿`
4. `記錄人：＿＿＿＿＿＿＿＿　　　陪同人員：＿＿＿＿＿＿＿＿（如有）`
5. （空行）
6. `【主述議題】` + 下一段為內容
7. （空行）
8. `【個案概況】` + 下一段為內容
9. （空行）
10. `【各項評估】` + 下一段為內容（可視個案增減：生活自理、醫療復健、居家無障礙環境、
    就學／就業與社會參與、家庭支持與照顧者負荷、經濟與福利資源使用——建議清單非強制）
11. （空行）
12. `【需求評估】` + 下一段為內容

## row 13（處遇計畫建議本文）段落順序

1. `－ 短期目標與行動（1–3 個月）`
2. （空行，內容插在這之前）
3. `－ 中長期目標與行動`
4. （空行，內容插在這之前）
5. `－ 轉介／資源連結建議`
6. （空行，內容插在這之前）
7. `－ 下次追蹤時間`

## 家系圖圖例（row 15，固定文字）

```
圖例：□男　○女　∕已故（打斜線）　＝婚姻（雙線）　≠離婚（斜線切雙線）　│親子關係（垂直線）
```
